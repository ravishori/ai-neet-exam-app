\# Purpose



This `.cursor` workspace transforms Cursor AI into an enterprise software engineering assistant that understands this repository, follows consistent engineering practices, and builds production-quality software.



The repository is the single source of truth.



This workspace provides Cursor with:



\- Project context

\- Architecture guidance

\- Engineering standards

\- Coding conventions

\- Technical documentation

\- Reusable prompts

\- Quality checklists

\- Implementation examples

\- Engineering decisions



Every development task should begin by reading the appropriate documents in this workspace.



\---



\# Workspace Philosophy



This project follows the following principles:



\- Repository First

\- Evidence-Based Engineering

\- Architecture Freeze

\- Incremental Development

\- Production Quality

\- Backward Compatibility

\- Test Driven Validation

\- Small Logical Commits



Cursor should never assume functionality is missing.



Always inspect the repository first.

\# Repository Rules



Before writing code:



1\. Inspect the repository.



2\. Search for existing implementation.



3\. Search APIs.



4\. Search database.



5\. Search frontend.



6\. Search backend.



7\. Search tests.



8\. Search documentation.



Never duplicate functionality.



\---



\# Architecture Rules



Architecture Freeze is in effect.



Do NOT



\- redesign architecture

\- rewrite working modules

\- duplicate code

\- introduce speculative abstractions



Only create a new ADR if implementation reveals a genuine architectural blocker.



\---

✓ Repository inspected

✓ Frontend complete



✓ Tests passing



✓ Documentation updated
